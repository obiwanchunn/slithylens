# This folder is the SlithyLens iPhone app (not documentation)

GitHub Pages publishes this folder as the website **https://obiwanchunn.github.io/slithylens/**.
It's named `docs` only because Pages' simple setting can publish just the repo's top level or a
folder called exactly `docs` (Settings → Pages → Deploy from a branch → `main` → `/docs`).
Don't rename it, or the site stops updating.

See the [main README](../README.md) for how to install and use it.
